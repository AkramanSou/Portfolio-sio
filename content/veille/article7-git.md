## Introduction

Git est un système de gestion de versions décentralisé créé par Linus Torvalds en 2005. Associé à GitHub, la plateforme de collaboration en ligne rachetée par Microsoft en 2018, il est devenu le standard absolu du développement logiciel moderne. En 2025, plus de 100 millions de développeurs utilisent GitHub pour héberger et collaborer sur leurs projets.

## Les concepts fondamentaux de Git

Git repose sur quelques concepts essentiels. Le **commit** permet de sauvegarder un état du code à un instant donné, accompagné d'un message descriptif. Les **branches** permettent de travailler sur des fonctionnalités en parallèle sans affecter le code principal. La **fusion** (merge) intègre ensuite le travail réalisé sur une branche dans la branche principale.

Le workflow le plus courant en équipe est le **Git Flow**, qui organise le développement autour de branches dédiées : `main` pour la production, `develop` pour le développement en cours, et des branches de fonctionnalités temporaires.

## GitHub en 2025 : bien plus qu'un hébergeur

GitHub a considérablement évolué pour devenir une véritable plateforme DevOps. GitHub Actions permet d'automatiser des pipelines de déploiement, GitHub Copilot assiste les développeurs dans l'écriture du code, et les GitHub Pages permettent d'héberger gratuitement des sites statiques — comme mon portfolio BTS SIO.

## Mon expérience avec Git

J'utilise Git et GitHub quotidiennement pour versionner mon portfolio et mes projets de formation. La commande `git push` après chaque modification importante est devenue un réflexe. Au-delà du simple sauvegarde, Git m'a appris à structurer mon travail en commits cohérents et à documenter mes changements.

## Mon analyse

Maîtriser Git est aujourd'hui aussi fondamental pour un développeur que de savoir écrire du code. C'est une compétence que tout recruteur dans le domaine informatique attend. Je recommande à tout étudiant en développement de s'y former le plus tôt possible, car les bénéfices se font sentir immédiatement sur l'organisation du travail.
