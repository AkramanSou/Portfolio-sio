J'ai testé les outils IA pour développeurs : ce qu'ils font vraiment bien (et mal)

Publié le 10/03/2026 | Tags : intelligence-artificielle ChatGPT Copilot test développement expérience

Démarche

Plutôt que de me fier uniquement aux articles et études, j'ai voulu tester par moi-même les principaux outils d'IA disponibles pour les développeurs. J'ai utilisé ChatGPT, GitHub Copilot et Claude sur des projets concrets réalisés dans le cadre de mon BTS SIO, notamment mon projet Angular SavonApi et mon site e-commerce.

Ce que l'IA fait vraiment bien

Génération de code répétitif

Sur mon projet Angular SavonApi, j'ai demandé à ChatGPT de générer la structure de base d'un composant Angular avec un service HTTP. Le résultat était correct et m'a fait gagner un temps considérable sur la partie "boilerplate" — c'est-à-dire le code de base que tout développeur doit écrire avant de commencer la vraie logique.

Débogage

Plusieurs fois, j'ai collé un message d'erreur directement dans ChatGPT. Dans la grande majorité des cas, l'IA a correctement identifié le problème et proposé une solution fonctionnelle. C'est particulièrement utile pour des erreurs classiques que l'on rencontre en début de formation.

Documentation

Demander à l'IA d'expliquer un concept ou de documenter une fonction existante fonctionne très bien. Sur mon portfolio Pelican, j'ai utilisé Claude pour m'aider à comprendre la syntaxe Jinja2 que je ne maîtrisais pas encore.

Ce que l'IA fait mal

Comprendre le contexte global d'un projet

Lorsque j'ai essayé de faire générer par l'IA une fonctionnalité complexe liée à plusieurs fichiers de mon projet e-commerce, le résultat était fonctionnel isolément mais ne s'intégrait pas correctement avec le reste du code. L'IA n'a pas de vision globale de l'architecture d'un projet.

Les choix techniques et d'architecture

Sur aucun de mes projets, l'IA n'a été capable de me conseiller sur la meilleure architecture à adopter en fonction des contraintes spécifiques. Ces décisions restent entièrement humaines.

La créativité et le design

Pour le design de mon portfolio, l'IA pouvait générer du CSS, mais les choix esthétiques, la cohérence visuelle et l'expérience utilisateur restaient entièrement de ma responsabilité.

Mon analyse

Après ces tests, ma conclusion est claire : l'IA est un outil puissant qui amplifie les capacités d'un développeur, mais elle ne le remplace pas. Elle excelle sur les tâches définies et répétitives, mais échoue dès qu'il faut du jugement, de la créativité ou une compréhension globale d'un projet. Pour un étudiant en BTS SIO, savoir utiliser ces outils efficacement est aujourd'hui une compétence à part entière — au même titre que maîtriser Git ou SQL.
